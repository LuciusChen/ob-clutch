#+title: ob-clutch

Org-Babel integration for the [[https://github.com/LuciusChen/clutch][clutch]] database client.

* Installation

Requires Emacs 29.1+ and =clutch= 0.7.2+:

#+begin_src emacs-lisp
(use-package clutch)
(use-package ob-clutch
  :after clutch)
#+end_src

Native MySQL and PostgreSQL blocks also require the optional =mysql= and =pgsql= packages, which Clutch loads on connect. SQLite uses Emacs's built-in support. Generic JDBC blocks require Clutch's JDBC adapter:

#+begin_src emacs-lisp
(require 'clutch-db-jdbc)
#+end_src

* Supported block types

- =mysql=
- =postgresql=
- =sqlite=
- =clutch= (generic entry point; use =:backend= to target JDBC databases like Oracle or SQL Server)

* Saved connections and passwords

=:connection= looks up entries in =clutch-connection-alist=. A saved =:backend= takes precedence over the block language; otherwise language-specific blocks use their own backend and generic =clutch= blocks default to =mysql=.

Password lookup follows Clutch's normal order:

1. Explicit =:password=
2. Saved =:profile-entry= (unless overridden by =:password= or =:pass-entry=)
3. =:pass-entry= via =auth-source-pass=
4. =auth-source-search= by =:host= / =:user= / =:port=

If a saved connection specifies none of =:password=, =:pass-entry=, or =:profile-entry=, Clutch falls back to using the connection name as =:pass-entry= (so pass entries like =mysql/dev= match =dev=). In a TRAMP Org buffer without an explicit transport header, Clutch applies =clutch-tramp-context-policy= before connecting.

* Header arguments

Common headers: =:connection=, =:backend=, =:host=, =:port=, =:user=, =:password=, =:database=, =:pass-entry=, =:ssh-host=, =:tramp-default-directory=, =:connect-timeout=, =:read-idle-timeout=, =:max-rows=, =:async=.

Backend-specific headers:

- PostgreSQL: =:schema=, =:tls=, =:sslmode=, =:query-timeout=
- MySQL: =:tls=, =:ssl-mode=
- JDBC: =:url=, =:driver-class=, =:sid=, =:schema=, =:catalog=, =:manual-commit=, =:query-timeout=, =:rpc-timeout=

Generic =:backend jdbc= blocks need an explicit =:driver-class= (for example =:url jdbc:h2:mem:demo :driver-class org.h2.Driver :user sa=) and the matching driver jar installed in Clutch's JDBC runtime.

=:max-rows= caps how many rows a block inserts into the Org buffer (default 1000 via =ob-clutch-max-rows=, since tens of thousands of table rows will stall Org). For a =SELECT= without its own row limit, =ob-clutch= asks for one extra row to detect truncation without fetching the whole table. When truncated, the table ends with a rule and =First N rows shown, more follow=; pass =:max-rows nil= (or a higher number) if another block reads the table or you want every row.

* Asynchronous blocks

Add =:async yes= to run a block without blocking Emacs on native MySQL, PostgreSQL, or JDBC connections (synchronous backends like SQLite still run immediately):

#+begin_src org
,#+begin_src postgresql :connection prod :async yes
SELECT pg_sleep(30), count(*) FROM orders;
,#+end_src
#+end_src

While running, =#+RESULTS:= shows =Running ob-clutch-N= and is replaced with the result table (or =Error: ...=) when done. Blocks sharing the same connection queue one after another (=Queued ob-clutch-N=); blocks on different connections run concurrently. Re-running a block does not cancel its earlier run, though only the latest run writes back, and a result you manually edited or deleted in the meantime is left untouched (also works with =:results append= and =:results prepend=).

Use =M-x ob-clutch-cancel-block-at-point= to cancel the latest run of the block at point: queued runs are dropped (=Cancelled=), while running statements are interrupted on the server and show the cancellation error (or the result if the query had already finished). A synchronous block targeting a connection busy with an async block fails with a busy error; add =:async yes= to queue it instead.

* Examples

MySQL:

#+begin_src org
,#+begin_src mysql :connection dev
SELECT 1;
,#+end_src
#+end_src

PostgreSQL:

#+begin_src org
,#+begin_src postgresql :host 127.0.0.1 :port 5432 :user postgres :database app :schema public :max-rows 20
SELECT now();
,#+end_src
#+end_src

SQLite (relative paths resolve against the Org file's directory; matching paths and =:memory:= share cached connections):

#+begin_src org
,#+begin_src sqlite :database /tmp/demo.db
SELECT sqlite_version();
,#+end_src
#+end_src

Saved JDBC connection:

#+begin_src org
,#+begin_src clutch :backend oracle :connection prod-oracle
SELECT sysdate FROM dual
,#+end_src
#+end_src

Inline JDBC connection:

#+begin_src org
,#+begin_src clutch :backend oracle :host db.example.com :port 1521 :user scott :sid ORCL
SELECT sysdate FROM dual
,#+end_src
#+end_src
